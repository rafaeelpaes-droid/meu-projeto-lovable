# Meu Projeto Lovable

Este repositório foi inicializado com uma base de app web moderna em React + Vite.

## Como rodar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
3. Acesse no navegador:
   ```bash
   http://localhost:3000
   ```

## Scripts disponíveis

- `npm run dev` — inicia o app em modo desenvolvimento
- `npm run build` — gera a versão de produção
- `npm run preview` — visualiza a build localmente

## Estrutura principal

- `src/App.tsx` — página principal
- `src/styles.css` — estilos do app
- `vite.config.ts` — configuração do Vite
